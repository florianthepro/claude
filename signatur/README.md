# E-Mail-Signatur – tanum consult · DIERCK Group

Signatur mit der Zugehörigkeit zur DIERCK Group als Logo-Zeile ganz unten:
**[tanum consult] part of the [dierck group]**

## Dateien

| Datei | Zweck |
|---|---|
| `signatur.html` | Die Signatur (im Browser öffnen, Inhalt kopieren und in Outlook unter *Einstellungen → E-Mail → Verfassen und Antworten → Signaturen* einfügen) |
| `logo-tanum-consult.png` | Offizielles tanum-consult-Logo (von tanum-consult.de, transparentes PNG) |
| `logo-tanum-consult-original.webp` | Original-Quelldatei des tanum-Logos |
| `logo-dierck-group.png` / `.svg` | dierck-group-Logo, **einzeilige Variante** – aus den Original-Vektorpfaden des offiziellen Logos (dierck-group.de) zusammengesetzt, da offiziell nur eine zweizeilige Version existiert |

## Hinweise

- Beide Logos sind im Bottom-Lockup verlinkt (tanum-consult.de bzw. dierck-group.de).
- Beim Einfügen in Outlook die Bilder direkt über *Bild einfügen* in die Signatur laden – relative Pfade funktionieren in E-Mails nicht.
- Die PNGs liegen in doppelter Pixelgröße vor (Retina); die Anzeigegröße ist im HTML per `width`/`height` gesetzt.
